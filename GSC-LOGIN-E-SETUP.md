## PASSO 4: Enviar Sitemap

**Após verificação:**

1. No menu esquerdo, clique **"Sitemaps"**
2. No campo no topo, digite: `sitemap.xml`
3. Clique **"Enviar"**

**Resultado esperado:**
```
✅ Enviado com sucesso!
```

**Você verá a lista:**
- Status: Sucesso
- Sitemaps enviados: 1

## PASSO 5: Solicitar Indexação (CRÍTICO!)

### A. Homepage

1. **Barra superior:** Clique em **"Inspetor de URL"**
2. Digite: `https://www.bestwellnessguide.com`
3. Pressione **Enter**
4. Aguarde 5 segundos (Google verifica)
5. Clique **"Solicitar indexação"** (ou **"Request Indexing"**)

**Resultado:** 
```
✅ Enviada para rastreamento
A URL foi enviada e será rastreada em breve
```

---
