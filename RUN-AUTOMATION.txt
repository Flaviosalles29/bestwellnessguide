🎯 PASSO 1: Google Search Console (Automático)
──────────────────────────────────────────────

⚙️ Instalando dependências:

  1. Abra PowerShell/Terminal
  2. Execute:
     pip install selenium

⚠️ Verificar Chrome instalado:
  • Windows: C:\Program Files\Google\Chrome\Application\chrome.exe
  • Se não tiver, baixe em: https://www.google.com/chrome/

▶️ Executar automação GSC:

  python gsc-automation.py

✅ O que vai acontecer:

  3. Script automatiza o resto (verificação + sitemap + indexação)
  4. Chrome fecha automaticamente

  pm2 start backlinks-automation.js --name "backlinks-scheduler"

🆘 TROUBLESHOOTING

❌ "Python not found"
  → Install Python: https://www.python.org/downloads/
  → Add to PATH during installation

❌ "Selenium not found"
  → Run: pip install selenium

❌ "Chrome not found"
  → Install Chrome: https://www.google.com/chrome/
  → Or edit gsc-automation.py to use your browser path

❌ "GSC automation fails"
  → Do it manually via browser: GSC-SETUP-GUIDE.md
  → Script is optional, manual is always an option

❌ "Backlinks automation not running"
  → Check: Is Node.js installed?
  → Run: npm install node-cron
  → Run: node backlinks-automation.js
